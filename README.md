## Project Overview

AI Divide is a compact AI business website delivered as a single web page. It provides Czech companies with a direct way to present their services while giving visitors an interactive welcome bot as an initial point of contact.

The project combines a streamlined online business presence with a business-oriented AI interaction. Its one-page approach works well for organizations that need a clear web introduction without maintaining a broad multi-page site.
